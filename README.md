# Retail Sales Performance Analysis

## Project Overview
This project focuses on analyzing Superstore retail sales data using Python and Power BI to uncover meaningful business insights and support data-driven decision-making. The analysis covers sales trends, customer behavior, regional performance, product profitability, discount impact, and interactive dashboard visualization.

## Objectives
- Analyze overall sales and profit performance.
- Identify region-wise sales trends.
- Determine top-performing customers.
- Identify loss-making products and sub-categories.
- Study monthly and yearly sales trends.
- Evaluate category and segment performance.
- Analyze the impact of discounts on profitability.
- Build an interactive Power BI dashboard for business reporting.

## Key Insights
- The West Region generated the highest sales and profit.
- The South Region showed comparatively lower performance.
- Technology emerged as the best-performing category.
- Certain sub-categories such as Tables and Machines contributed to losses.
- Higher discounts negatively affected profitability.
- Sales increased during the later months of the year, indicating seasonal trends.

## Conclusion
The project successfully transformed raw retail data into actionable business insights using Python and Power BI. The findings can help organizations improve decision-making, optimize product strategies, reduce losses, and enhance overall business performance.
